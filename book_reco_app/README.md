# 书籍推荐系统（Flask）

一个功能完整的书籍推荐系统示例，包含：

- 首页推荐（含协同过滤个性化推荐）
- 分类筛选 + 关键词搜索
- 书籍详情页
- 收藏功能
- 用户评价（评分+评论）
- 分页导航
- 登录/注册系统
- 用户端与管理员端

## 技术栈

- Python 3
- Flask
- SQLite
- Jinja2 + CSS

## 快速启动

```bash
cd book_reco_app
python3 -m venv .venv
source .venv/bin/activate
pip install flask werkzeug
python app.py
```

打开浏览器访问：`http://127.0.0.1:5000`

首次运行会自动初始化数据库。

## 演示账号

- 管理员：`admin / admin123`
- 用户：`alice / user123`

## 协同过滤说明

系统使用**基于用户的协同过滤**：

1. 根据用户评分矩阵构建每个用户的评分向量。
2. 使用余弦相似度计算目标用户与其他用户的相似度。
3. 对“相似用户喜欢、但目标用户未评分”的书籍进行加权打分。
4. 输出 Top-N 作为个性化推荐。

若用户评分数据不足，则回退到“高评分热门书籍推荐”。
